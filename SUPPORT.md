# Help and bug reports

Start with [local setup](docs/BETA-SETUP.md), [usage](docs/USAGE.md) and [known limits](docs/BETA.md). Check that your installed version matches the documentation and that the operator has provisioned the required scoped grants.

For general questions or reproducible bugs, use the repository's Issues tab when the project is published. Include your commit/version, platform, steps, expected and actual behavior, and a minimal synthetic example. Do not attach database dumps, exports, tokens, session cookies, credentials or patient records.

For suspected vulnerabilities, use [security reporting](SECURITY.md). There is no staffed support desk, guaranteed response time or production support commitment for this experimental Beta.
