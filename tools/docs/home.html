Build from sourceShell
# Get the source
git clone https://github.com/xarhang/liteCR.git
cd liteCR

# Build the embedded web interface
cd apps/web
npm ci
npm run build
cd ../..

# Compile the server
cargo build --locked -p litecr-server

This builds the application. Database migration, OIDC and access provisioning are separate setup steps.

A few practical questions

Before you start.

Need more detail? Read the support guide.

Does liteCR require OpenCR?

No. liteCR runs with its own Rust server, PostgreSQL database and configured IdP. OpenCR interoperability is a separate integration concern and has not been verified for this Beta. See the architecture.

Can I search for someone by name?

Person search currently accepts an exact public ID or alias. Demographic candidate comparison uses the separate matching workflow. See usage and the API overview.

Can I run the registry on GitHub Pages?

No. This site hosts static documentation. Registry operations require the backend, PostgreSQL and OIDC. Follow local setup to evaluate the application.

How can I contribute or report a bug?

Use a minimal synthetic reproduction and include your commit/version. Never include patient data, cookies or credentials. Read contributing; suspected vulnerabilities follow the security reporting process.
